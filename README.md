# 🧠💰 Precificação de Ativos de Renda Fixa com Enfoque em Computação Quântica

Este projeto investiga metodologias para a **precificação de instrumentos de renda fixa**, como títulos públicos e privados, integrando fundamentos de **Finanças Quantitativas** e **Computação Quântica**.

## 🚀 Objetivo

O objetivo é **comparar modelos clássicos de avaliação de ativos com abordagens baseadas em computação quântica**, visando avaliar a aplicabilidade de algoritmos quânticos na resolução de problemas financeiros complexos, como o cálculo do valor presente líquido (VPL) e da taxa interna de retorno (TIR).

## 🧩 Abordagem Híbrida

- **Clássico**: Implementações com `NumPy`, `Matplotlib` e fórmulas financeiras tradicionais.
- **Quântico**: Modelos com `Qiskit` (IBM Quantum) ou `PennyLane`, aplicando algoritmos como:
  - **Variational Quantum Eigensolver (VQE)**
  - **Quantum Approximate Optimization Algorithm (QAOA)**

> Este projeto integra aprendizado de máquina quântico, otimização e simulação de fluxos de caixa com o objetivo de investigar os avanços da **5ª geração da computação** na área financeira.

## 🔍 Funcionalidades

- 🧮 Cálculo de VPL e TIR
- 📊 Análise de sensibilidade de taxas de juros
- 🧠 Simulação de precificação com modelos quânticos
- 🔬 Comparação entre métodos clássicos e quânticos
- 🌐 Interface interativa com `Streamlit` *(em desenvolvimento)*

## 📚 Tecnologias

| Clássicas     | Quânticas       |
|---------------|-----------------|
| Python, NumPy | Qiskit, PennyLane |
| Matplotlib    | IBM Q Experience |
| Streamlit     | Cirq (em testes) |

## 📈 Exemplos Incluídos

- Precificação de título pré-fixado
- Modelo de renda fixa híbrida indexada ao IPCA
- Estudo de caso com ruído quântico simulado
- Avaliação via circuito quântico de valor presente

## 🧠 Motivação

A Computação Quântica promete resolver classes de problemas que crescem exponencialmente com o número de variáveis. O mercado financeiro é naturalmente **altamente dimensional**, sendo um campo fértil para explorar esses algoritmos.

> “Quem dominar a computação quântica e a inteligência artificial dominará os mercados de amanhã.” — *Visão do projeto*
